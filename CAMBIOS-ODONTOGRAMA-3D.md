# Actualización de dentadura 3D

- Modelo paramétrico con encías, incisivos, caninos, premolares y molares.
- Giro horizontal completo, exploración vertical, zoom y desplazamiento.
- Control de apertura, vistas de cámara y aislamiento de cada arcada.
- Dentición permanente de 32 piezas o temporal de 20.
- Identificación FDI, selección de corona y registro por superficie.
- Colores negro, amarillo y verde, borrado y deshacer compartidos con 2D.
- Guardado con el servicio existente, sin modificaciones de tablas.
- Recursos Three.js locales y licencia MIT incluida.
- Vista 2D accesible si WebGL no está disponible.
- Adaptación a móvil y controles para seleccionar por teclado.
- Corrección de la expresión HTML del usuario en la configuración inicial.
- JAR compilado con Java 21 incluido en bin.
